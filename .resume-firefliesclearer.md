## Plan-vs-reality deviations (already-known traps)

Project memory `project_firefliesclearer.md` has the full list. Highlights:

- `Pipeline.archive_one(meeting)` / `purge_one(meeting)` take a `Meeting`, not meeting_id.
- `Manifest.open(path)` not `Manifest(path)`; `Manifest.transition(mid, *, to=, at=, ...)` keyword-only.
- Modern Starlette `TemplateResponse(request, "name.html", {ctx})`.
- `asyncio_mode = "auto"` in pytest — never `@pytest.mark.asyncio`.
- Ruff selects `["E","F","W","I","N","UP","B","SIM","RUF"]` — no `SLF001`/`BLE001` noqa.
- CSRF middleware urlencoded-only.
- mypy class-scope name resolution gotcha: `class Foo: def list(self)` shadows builtin even with PEP 563. Use `_List = builtins.list` alias (see `application/preset_service.py`).
- `tomli_w` cannot serialize Python `None` — use `model_dump(mode="json", exclude_none=True)`.
