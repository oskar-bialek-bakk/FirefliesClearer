## Plan-vs-reality deviations (already-known traps for next phase)

These bit Phase 4-5 implementers; project memory `project_firefliesclearer.md` has the full list. Highlights:

- **`Pipeline.archive_one(meeting)` / `purge_one(meeting)`** take a `Meeting` object, not meeting_id.
- **`Manifest.open(path)` not `Manifest(path)`**; `Manifest.transition(mid, *, to=, at=, ...)` keyword-only on `to`/`at`.
- **Modern Starlette `TemplateResponse(request, "name.html", {ctx})`** — plan's old form raises TypeError.
- **`asyncio_mode = "auto"`** in pytest — never add `@pytest.mark.asyncio`.
- **Project ruff selects `["E","F","W","I","N","UP","B","SIM","RUF"]`** but NOT `SLF001`/`BLE001` — don't add those noqa directives, they trip RUF100.
- **CSRF middleware urlencoded-only**, double-submit cookie pattern; HTMX POSTs include `_csrf` via `hx-include="[name='_csrf']"` or wrapping form.
- **Tests for web routes use raw `sqlite3.connect(check_same_thread=False)`** in `tests/web/conftest.py:configured_app` — `Manifest.open` thread-pins, `TestClient` dispatches handlers in worker threads.
- **TestClient context-manager + `client.portal.call(...)` pattern** required for async ops (see `tests/web/routes/test_cleanup_step3.py:27-42` for the canonical block comment).
