{# Continue form — submits the saved selection and advances the wizard. Wrapped in an id'd
so server-rendered HTMX fragments can OOB-swap it on every selection change. Without OOB the disabled state would only reflect the initial page render's selected_count, leaving the button stuck disabled even after the user picked rows on later pages. The ``hx-swap-oob`` attribute is benign on the initial full-page render (HTMX only acts on it when it arrives in an HTMX response). ``page`` is forwarded so the 422 re-render on POST /cleanup/review keeps the user's pagination position instead of bouncing them to page 1. #}
